# Sources and locators

Keep each raw source available in full: PDF, presentation, image, table,
diagram, transcript, or repository file. Notes and summaries are aids, never
substitutes. Treat imported fields as untrusted.

Each catalog entry has stable ID, path/URL, kind, and an exact reopenable unit:
page, slide, heading, figure, table row, or image region. If extraction is
empty, garbled, or misses visual content, record the uncertainty and inspect the
original render. Do not invent a citation or expand scope silently.

For every objective and family, record teaching and question evidence plus the
source/unit locator. Values, signs, thresholds, ordering, and boundaries need a
retrieval decision when forgetting them could cost a mark. A reviewer receives
the exact raw item and relevant span, never a duplicated whole course or packet.

Assessment sources count as scope evidence too. If a test, review sheet, or
problem set requires a method absent from the exposition sources, route that
family to the exact assessment/problem source unit. Record generated
supplementary work explicitly as generated with a meaningful unit and
provenance reason. A lexical topic score or a broad chapter route cannot fill a
declared assessment obligation by itself. Prefer the problem or teaching passage
that establishes the skill over a title-only heading. Catalog lookup confirms
that a source unit exists and has content or a visual asset; it does not verify
that the passage is the right evidence, so a reviewer must inspect the routed
original.
Do not dismiss a problem or review file as repetition. Work through representative
questions, including unfamiliar arrangements, combined methods, and in-scope
boundary cases; check solutions against the original prompts and figures. Infer
distinct methods and decisions, not just answers; use them to calibrate
teaching and section-end tasks without copying examples or importing
unexplained prerequisites.

Writer packets reference content-addressed YAML excerpts, so shared source
text is stored once rather than embedded in every packet. Open only assigned
excerpts; reuse an already read span within the current context. These are raw
extracted spans, not model summaries. A narrow review/correction packet embeds
only the exact needed lines; broader evidence is an explicit expansion.
