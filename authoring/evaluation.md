# Evaluation and limits

## Teaching overhaul

Teaching briefs now record the intended reasoning, local prerequisite IDs,
representation job, and practice target. Explicit substantive introduction
anchors distinguish available teaching from a mention. Writer packets select
that evidence and preserve reader priorities; a shared outline avoids copying
the course into every lesson. `author preview --sub` reuses production lane,
depth and HTML rendering for composition inspection. Component interaction
and final layout still require the real reader.

Optional summaries no longer create audit debt. A `core` belongs to full
reading, a `gist` belongs to Notes, and neither is required. Existing authored
content and validation signatures are preserved. The ordinary flow
targets one writing pass; local format checks are available without mandatory
reviewer handoffs. Consolidated review/correction remains a backstop.

`tests/fixtures/author-teaching` contains explicitly synthetic procedural,
conceptual and interpretive examples. One bounded cheap-worker draft needed
one schema correction; it does not establish reliable first-pass production.
Its dilution answers were independently calculated, its feedback sequence
checked against the stated rule, and its interpretation checked against the
source's observational limits. Integration tests exercise clean completion
in all three modes and prerequisite readiness. Browser checks use the real
reader at desktop and mobile widths, including Notes, a table, and local help.

Measure task success, time to success, external clarification, relevant
transfer, and delayed retention with learners before claiming improved
learning. No learner study or demonstrated subscription savings is claimed.
Context-size reporting is an estimate for packet/rules/excerpts; sharing files
does not make model input free. Keep the research rationale outside default
writer packets. Relevant foundations: [IES instruction guide](https://ies.ed.gov/ncee/wwc/PracticeGuide/1),
[NSW cognitive-load guidance](https://education.nsw.gov.au/about-us/education-data-and-research/cese/publications/practical-guides-for-educators/cognitive-load-theory-in-practice),
and [Chi et al. on self-explanation](https://doi.org/10.1207/s15516709cog1302_1).

## Source-to-task teaching regression

`tests/fixtures/teaching-review/` supplies synthetic raw sources, original source
questions, mixed-quality candidates, and a separate evaluator key. Its README
describes bounded review using the existing workflow; none of this corpus is
loaded into ordinary creator packets. The integrity test checks source/case
routing only. It does not award teaching quality by matching prose or counting
diagrams.

A blind reviewer using the revised rules identified the missing ordering and
exhaustion decisions and weak practice in the procedural candidate, accepted
adequate prose-only mechanism/interpretation cases, and rejected unnecessary
learner research. A separate cheap-writer pilot drafted those three subjects
from the raw sources and their questions. Independent review accepted the
procedure and mechanism and requested removal of one repeated interpretation
paragraph; the writer removed it and the reviewer accepted that correction.
This is bounded evidence about author/reviewer behavior, not learner mastery.
Local pilot artifacts and context measurements are under
`.scratch/course-creator-pilot/`.

Default instruction estimates changed from 3710 to 3856 tokens for planners,
3114 to 3257 for writers, and 3534 to 3709 for reviewers. A writer packet selecting
grid, self-response, and bank formats changed from 7269 to 7487. These are rule
selection estimates, not total run usage or demonstrated subscription savings.

## Earlier context work

The ECE36800 audit found excessive coordination, broad objective-derived
packets, duplicate source reading, correction churn and late publish-field
repairs. Cheaper writing alone did not remove repeated input costs.

Changes address those causes:

| Failure | Change | Purpose |
| --- | --- | --- |
| Inventory became an oversized production outline | Goal-based scope dispositions; shared family evidence; remove fixed per-lesson teaching forms | Preserve necessary learning without one lesson/question per inventory entry |
| Source text repeated across packets | Lesson-local assignments, compact outcomes and content-addressed excerpt paths | Store raw spans once and avoid duplicate packet input |
| Broad rereading and serial correction dispatch | Focused original-item review, complete review before one consolidated correction set | Prevent repeated review and new-example churn |
| Missing tags/markers discovered at finish | First-lesson publish-format pilot, before bulk writing | Expose schema/evidence mistakes before copying them throughout the course |

Purged obsolete instruction-token tables, superseded pilot narratives and the
mandatory default checklist copy. The checklist remains available on demand;
canonical scope and review instructions replace conflicting fixed-form rules.

Regression checks cover selected original items, exact source lines, shared
excerpt reuse, scope dispositions, multi-family evidence, manual whole-course
handoffs, local workspace selection and early publish-format failures.

The earlier simple resistor/inclusion-exclusion pilots showed that cheap
writers can finish bounded tasks; they did not establish full-course quality
or subscription savings. A small review experiment detected the same four
known defects with broad and narrow Sol context; Luna initially missed two
and caught them under concrete calculations. This supports focused checks,
not statistical quality equivalence or an assumed natural error rate.

Measure real runs from a usage baseline. Disk caching does not make model
input free; fresh agents still have startup/context costs. No percentage
savings or mastery claim follows from mechanical coverage or format checks.
