# Practice

For a small course, keep lesson checks as inline typed questions. When learners
need repeated practice, reuse across lessons, or shared history, use the course
question bank: define each task type in `questions/skills.yaml` (legacy `types.yaml` remains readable), store each
question once in `questions/bank.yaml`, and add its stable ID where it should
appear. Ordinary bank items default to practice. Keep reserved checks separate.

Write a variant only when a changed surface or context helps the learner
transfer the same skill. Vary the decision or reasoning demanded, not just the
numbers. Check each answer independently, explain the tempting error where
useful, and keep source and verification evidence with the item. There is no
fixed number of items that proves sufficient practice.

Select the `bank` need to load the question-bank schema and review rules. See
[`question-bank.md`](question-bank.md) and
[`formats/question-bank.md`](formats/question-bank.md).
