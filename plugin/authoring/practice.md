# Practice variants

Add `practice/<concept>.yaml` only when a skill needs another surface, context,
or difficulty. The concept must exist. A variant asks for the same kind of
response as the worked skill while changing the surface enough to prevent item
memorization. It has a valid current response shape, a distinct prompt, and a
`verified:` date after an independent derivation.

A specific value in a `key` that could cost a mark when forgotten needs a
retrieval decision. Detail retention, transfer, and real discrimination needs
justify variants; a fixed number per concept does not. Practice inherits the
concept's category and never carries a quiz `type` identity.
