# Cross-course links

```yaml
h: '<p>This builds on <a href="#/other-course/s6-1">first-order transients</a>.</p>'
```

Use a full course route with a subsection anchor. The target must resolve among
courses on disk, and non-redundancy applies across courses. The link is a
reader aid; it does not license a term unless the current course declares it as
background or defines it locally.
