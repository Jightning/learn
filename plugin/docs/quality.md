# Optional quality checks

When asked to review diagrams, use one cheap agent and one browser session
for the requested batch. Visually check clarity and agreement with the text
on laptop and phone. Fix simple defects; remove confusing diagrams that are
costly to repair, preserving essential information in text. Keep removed assets
and note why in `authorComment`; restore only if the user asks. Recheck changes
once. This applies to all diagram types and runs only when requested.
